# **App Name**: NextSite Generator

## Core Features:

- Input Fields: Allow users to input the desired website name and a brief description of the website's purpose.
- AI-Powered Suggestion: Use a generative AI model to generate the home page text and a basic website structure based on the user's input. The AI model is used as a tool to incorporate additional, helpful information to improve the suggestion.
- Preview Display: Display the generated website structure and home page text in a preview format.
- Download Project: Allow users to download the generated Next.js project as a zip file.
- Blog Post Listing: Display blog posts with title, excerpt, and featured image.
- Single Blog Post View: Display a single blog post with full content, author, and date.
- Course Listing: Display a list of available courses with title, short description, and instructor.
- Single Course View: Display a single course page with detailed description, syllabus, instructor bio, and student testimonials.
- Tag Suggester: AI powered tool to suggest tags for blog posts based on content.
- Home Page: Display a landing page with featured courses and blog posts.
- Login Page: Allow users to log in to their accounts.
- Registration Page: Allow users to create new accounts.
- About Page: Display information about the website and its purpose.
- Contact Page: Allow users to contact the website administrators.
- Media Upload: Enable uploading images and videos in blog posts.

## Style Guidelines:

- Primary color: White or light gray for a clean and modern look.
- Secondary color: A calm blue (#3498db) for headings and accents.
- Accent: Green (#2ecc71) for buttons and interactive elements.
- Clean and structured layout with clear sections for blog posts and course information, using Tailwind CSS grid and flexbox.
- Clean and readable sans-serif fonts for body text and headings, using Tailwind CSS.
- Use a consistent set of icons for navigation and course features, styled with Tailwind CSS.
- Subtle animations for loading states and user interactions to enhance the user experience.
